# CASH AL v6.0.0

نسخة إعادة بناء كاملة لمنصة CASH AL، مصممة لتعمل على Vercel مع PostgreSQL.

## ما تم ربطه
- حسابات مستقلة وID فريد لكل مستخدم.
- تسجيل دخول بجلسة HttpOnly + CSRF.
- منع تكرار الهاتف/البريد على مستوى قاعدة البيانات.
- محافظ Safe وSmart لكل عملة مدعومة.
- إيداع يدوي 0% مع مراجعة أدمن.
- مكافأة Smart بنسبة 3% عند اعتماد الإيداع، مع Ledger منفصل للمكافأة.
- سحب يدوي برسوم 5% وحالة Pending قبل الإتمام.
- تبديل عملات بسعر حي من الخادم ورسوم 5%، مع تسجيل الحركات.
- لوحة Super Admin عبر `/eng.ali.soft`.
- تعديل الرصيد عبر Public ID والعملة والمحفظة، مع Before/After وسبب العملية.
- KYC من ملف المستخدم وحالات مراجعة.
- Telegram notifications عبر متغيرات بيئة سرية.
- Audit Log وLedger.
- واجهة عربية RTL متجاوبة.

## إعداد الإنتاج
يجب إنشاء متغيرات Vercel التالية في Project Settings → Environment Variables:

- `DATABASE_URL` — رابط PostgreSQL حقيقي.
- `JWT_SECRET` — سر عشوائي طويل.
- `CRON_SECRET` — سر عشوائي طويل (محجوز للمهام المجدولة المستقبلية).
- `ADMIN_PASSWORD` — كلمة مرور Super Admin.
- `TELEGRAM_BOT_TOKEN` — Bot Token جديد بعد تدوير التوكن الذي تم كشفه في المحادثة.
- `TELEGRAM_CHAT_ID` — Chat ID الخاص بالأدمن.

لا تضع ملف `.env` الحقيقي داخل مستودع عام أو ZIP يتم مشاركته. Vercel يدير أسرار الإنتاج من إعدادات المشروع.

## التشغيل المحلي
```bash
npm install
npm start
```
ثم افتح `/` للموقع و`/eng.ali.soft` للوحة الأدمن.

## ملاحظة مهمة
لا يمكن تضمين `DATABASE_URL` الحقيقي أو سر Telegram الإنتاجي بأمان داخل ZIP. لذلك هذه النسخة لا تدّعي وجود قاعدة بيانات أو Telegram مُهيّأين فعليًا قبل وضع أسرار بيئة الإنتاج في Vercel.
